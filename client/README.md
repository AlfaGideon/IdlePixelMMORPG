# Клиент IdlePixelMMORPG (Godot 4)

## Как открыть

1. Установить **Godot 4.7** (стандартная сборка, не .NET): https://godotengine.org/download
2. `Godot → Import` → выбрать `client/project.godot` → `Import & Edit`.
3. `F5` — запуск. Окно откроется 360×640 (как телефон): сначала загрузочный экран
   с костром и бегущим героем, затем — пустая игровая сцена (её наполняем дальше).

Проект специально сделан так, чтобы открыться в чистом редакторе **без ручной настройки**:
нет `.import`-файлов, нет плагинов, нет внешних зависимостей.

## Что внутри

| Файл | Назначение |
|---|---|
| `project.godot` | 720×1280, `handheld/orientation=6` (sensor: и портрет, и ландшафт), `stretch/canvas_items` + `aspect=expand`, рендерер `gl_compatibility` (нужен для web), фильтр текстур `nearest` (пиксель-арт) |
| `boot.tscn` | экран загрузки: пиксельная сцена + логотип + полоска прогресса |
| `scripts/boot.gd` | грузит `main.tscn` через `ResourceLoader.load_threaded_*`, держит минимум 2.2 с |
| `ui/pixel_scene.gd` | живая пиксельная сцена: рисует кадр в сетке 120×214 и растягивает nearest |
| `main.tscn` | игра после загрузки (пока пустой `Control`) |
| `art/logo.png` | сплэш-логотип 2304×608 |
| `art/logo-square.png` | квадратный логотип для сторов и шапок |
| `art/icon.png` | иконка приложения 512×512 |
| `ui/kit.gd` | `UIKit`: фабрики узлов (label / panel / box / spacer) и палитра |
| `assets/fonts/` | Source Sans Pro (SIL OFL 1.1) — нужен для кириллицы |
| `icon.svg` | старый плоский значок (оставлен как запасной) |

## Загрузочный экран

Что происходит при запуске:

1. Godot показывает **однотонный фон** вместо своей заставки (`boot_splash/show_image=false`).
2. Открывается `boot.tscn`: ночной лагерь, костёр, стража, палатка, луна, звёзды.
3. Параллельно в фоне грузится `main.tscn` (`ResourceLoader.load_threaded_request`).
4. По полоске бежит герой: кадры меняются 9 раз в секунду, силуэт подсвечен костром снизу.
5. Когда сцена готова и прошло не меньше 2.2 с — переход в игру.

Сцена рисуется **попиксельно в сетке 120×214** и растягивается целочисленным
`nearest`-масштабом. Так пиксель-арт остаётся пиксель-артом на любом DPI,
а не превращается в мыло. 30 кадров в секунду: анимация живая, батарея не страдает.

Проверить вид без сборки: `python3 tools/preview_boot.py` — PNG-кадры в `tools/preview/`
рисуются той же математикой, что и `pixel_scene.gd`.

## Логотип и иконка

Генерируются из тех же спрайтов: `python3 tools/make_assets.py`.
Пиксельный шрифт 5×7 лежит в `tools/pixelfont.py` (латиница, цифры, пунктуация).

## Почему UI собирается кодом, а не сценой

Это осознанный компромисс на старте: сцены удобны, но их текст нельзя проверить
без редактора, а здесь каждая правка должна быть проверяемой. Как только появится
полноценный экран (аванпост, герой, бой), он переедет в `.tscn`, а `UIKit` останется
для повторяющихся элементов. Дерево контейнеров всё равно строится одинаково.

## Портрет и ландшафт

- `BoxContainer.vertical` переключается по соотношению сторон — контейнер сам
  перестраивает дочерние элементы, вручную ничего не двигаем.
- Отступы берутся из `DisplayServer.get_display_safe_area()` и пересчитываются
  из физических пикселей в единицы дизайна.
- Раскладка обновляется по сигналу `get_viewport().size_changed`.
