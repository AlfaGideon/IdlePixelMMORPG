# IdlePixelMMORPG

Idle-**RPG** на движке **Defold**: боевые классы, монстры и уровни, общий мир, аукцион и мировые события.
Платформы: Android (APK) и Web. Монетизация — внешняя, через веб-магазин и промокоды.

📄 **[План разработки](docs/PLAN.md)** — концепт, боевая система, архитектура, адаптивный UI, дорожная карта.
📱 **[Клиент](client/README.md)** — скелет Defold-проекта (мобильный шаблон + динамическая ориентация).

## Состояние

| Часть | Статус |
|---|---|
| Концепт и план | v0.2, обсуждается |
| Клиент `client/` | скелет: HUD-заглушка, responsive-раскладка по safe area |
| Сервер `server/` | ещё нет |
| Конфиги `shared/` | ещё нет |

## Структура

```
client/   -- Defold-проект (открывать client/game.project)
docs/     -- план и спеки
tools/    -- вспомогательные скрипты (проверка ссылок в клиенте)
server/   -- Node.js + TypeScript (появится на итерации 0)
shared/   -- протокол и игровые конфиги (появится на итерации 0)
```

## Проверка клиента без Defold

```bash
python3 tools/check_client_refs.py client   # все ссылки на ресурсы разрешаются
```

Полноценная сборка APK/Web — в GitHub Actions (JDK и SDK локально не нужны).
