# IdlePixelMMORPG

Idle-**RPG** на **Godot 4**: боевые классы, монстры и уровни, общий мир, аукцион и мировые события.
Платформы: Android (APK) и Web. Монетизация — внешняя, через веб-магазин и промокоды.

📄 **[План разработки](docs/PLAN.md)** — концепт, боевая система, архитектура, адаптивный UI, дорожная карта.
🎮 **[Клиент](client/README.md)** — проект Godot 4 (портрет/ландшафт, safe area, пиксель-арт).

## 📱 Скачать APK

Каждый пуш в `client/**` автоматически собирает debug-APK и публикует его в релизах:

**https://github.com/AlfaGideon/IdlePixelMMORPG/releases**

Установка: открыть ссылку на телефоне → скачать `IdlePixelMMORPG-debug.apk` → разрешить
установку из неизвестных источников. Сборка подписана debug-ключом, поэтому Play Protect
может предупредить — это нормально для тестовых сборок.

Что показывает эта сборка: вместо заставки Godot — живой пиксельный экран загрузки
(ночной лагерь, костёр, стража, падающие звёзды) и полоска, по которой бежит герой.
Затем — пустая игровая сцена. Логотип игры стоит в шапке экрана загрузки.

Превью экрана без установки: `tools/preview/frames.png`.

## Проверка без движка

```bash
python3 tools/check_godot_project.py client      # ссылки res://, узлы сцен, ресурсы
gdlint client/scripts client/ui                  # линт GDScript (pip install gdtoolkit)
python3 tools/check_defold_refs.py               # проверка legacy-проекта
```

Сборка APK/Web — в GitHub Actions: локально нужны экспорт-шаблоны Godot и Android SDK/NDK.

## Ассеты

- `tools/make_logo.py` — собирает `client/art/logo.png`, `logo-square.png`, `icon.png`
  из нарисованного исходника `tools/art-src/logo-source.png`;
- `tools/make_runner.py` — рисует спрайт-лист героя `client/art/runner.png`
  (6 кадров бега, 20×24) и превью `tools/preview/runner_sheet.png`;
- `tools/make_assets.py` — пиксельный шрифт и остальная графика.

Проверить итог без телефона: `python3 tools/make_logo.py` соберёт
`tools/preview/boot_compose.png` — загрузочный экран со сценой и логотипом.

## Игровой интерфейс

`client/main.tscn` → `client/ui/game_hud.gd` (`class_name GameHud`). HUD рисуется
в буфер 180×320 и увеличивается целочисленно, поэтому рамки, шрифт и иконки
остаются пиксельными на любом экране (и в портрете, и в ландшафте).

Разметка:
- **шапка** — лицо героя, уровень, здоровье, опыт, золото;
- **центр** — вкладки: БОЙ (арена, кнопки УДАР/АВТО, журнал событий), ТРУД,
  СУМКА, КАРТА, ЛАВКА;
- **футер** — пять кнопок-вкладок с пиксельными иконками и разделителями.

Шрифт интерфейса — тот же пиксельный 5×7, что у логотипа: `tools/pixelfont.py`
(с кириллицей) → `python3 tools/make_font_gd.py` → `client/ui/pixel_font.gd`.

Проверка без телефона: smoke-тест в CI снимает кадр интерфейса в
`ci-logs/game_capture.png` (переменные `GAME_CAPTURE`, `GAME_CAPTURE_PATH`).

## Герой на полоске загрузки

По полоске бежит персонаж выбранного класса. Спрайты (6 кадров бега, 24×28) —
`client/art/classes/runner_<класс>.png`, их рисует `tools/make_class_runner.py`
(воин, маг, дуэлянт, разбойник, жрец, паладин, следопыт).

Класс задаётся настройкой проекта:

```ini
[game]
player/hero_class="warrior"   ; пусто — обычный герой
```

Когда появится экран выбора класса, туда же можно писать через
`ProjectSettings.set_setting("game/player/hero_class", chosen)` и сохранять
выбор в профиле игрока — заставка подхватит его при следующем запуске.
