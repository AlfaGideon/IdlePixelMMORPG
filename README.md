# IdlePixelMMORPG

Idle-MMORPG на движке **Defold**: общий мир, аванпосты игроков, аукцион и мировые события.
Платформы: Android (APK) и Web. Монетизация — внешняя, через веб-магазин и промокоды.

📄 **[План разработки](docs/PLAN.md)** — концепт, архитектура, адаптивный UI, дорожная карта.
