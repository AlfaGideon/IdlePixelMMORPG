# Канон стиля прототипа — IdlePixelMMORPG (v2, современный HD-пиксель)

Репозиторий на момент прототипирования содержит только `README.md`, поэтому канон
выводится из названия проекта: **pixel-art MMORPG с idle-механикой**.
Важное уточнение заказчика: пиксель нужен **современный**, а не «древние покемоны».
Первая версия канона (8/16-bit, чиби, 5 цветов, деревянные рамки с заклёпками)
отклонена и больше не используется.

Ниже — жёсткие правила, которым подчиняется КАЖДАЯ картинка прототипа.
Ни один экран не имеет права от них отступать.

## 1. ЧТО ЗАПРЕЩЕНО (анти-канон)

- ❌ 8-bit / GameBoy / NES-эстетика, «древние покемоны», чиби-спрайты,
  большеголовые персонажи, игрушечные пропорции.
- ❌ Плоские мультяшные заливки, палитра из 5 цветов, толстые 2px обводки
  вокруг всего, «весёлые» закруглённые кнопки.
- ❌ Деревянные/каменные скошенные рамки с заклёпками, пергаментные плашки,
  средневековый «фэнтези-UI из 2005 года».
- ❌ Размытие, сглаживание, градиенты, 3D-рендер, векторная иллюстрация,
  фотореализм, «жидкая» AI-живопись поверх пикселей.
- ❌ Длинные надписи и псевдотекст на самих картинках.

## 2. База (общее для всех экранов и обоих вариантов)

- Формат: мобильный экран, портрет **9:16**, изображение «в край» (full-bleed),
  без рамки телефона, без рук, без мокап-подложки, без коллажа/сетки вариантов.
- Техника: **современный высокодетализированный pixel-art** (HD-2D / neo-pixel-art).
  Плотные кластеры 1px-пикселей, спрайты 64–128 px с нормальными человеческими
  пропорциями, богатая палитра 20–30 оттенков, ручной дитеринг, цветовые рампы.
- Свет и сцена: объёмные лучи, bloom, rim light, ambient occlusion, атмосферный
  туман, светящиеся частицы, параллаксные слои глубины, кинематографичный
  depth-of-field на заднем плане. Взрослый, «премиальный», кинематографичный арт.
- Проекция: ортографическая / слегка изометрическая для локаций, фронтальная для боя.
- Типографика: только мелкие технические глифы пиксель-шрифта — цифры, `LV`,
  `HP`, `DPS`, `GOLD`, `+`. Русские подписи на картинках не рисуются — названия
  экранов живут в HTML-прототипе.

## 3. Постоянный «хром» интерфейса (главный якорь единообразия)

Современный MMO-HUD, одинаковый на **всех** экранах; меняется только активная вкладка:

1. Тонкие **1px** пиксельные бордеры, полупрозрачные тёмные «стеклянные» панели,
   тонкие неоновые акцентные линии — без скосок, без заклёпок, без дерева.
2. Верхняя строка: три компактных капсулы ресурсов (монета / кристалл / энергия)
   и бейдж `LV` справа, тонкий сегментированный `EXP`-бар под ней.
3. Нижняя панель навигации: ровно **5** микро-иконок
   `лагерь → меч → герой → сумка → карта` (6-й экран добавляет «магазин»),
   активная иконка подсвечена акцентным неоном.
4. Плотная, но чистая сетка данных: сегментированные бары `HP` / `DPS`,
   микро-иконки предметов 16×16 с тонкой рамкой редкости, компактные тултипы.
5. Акцентный цвет варианта используется только для подсветки, урона и лута.

## 4. Варианты (один стиль, две цветовые grading-версии)

Отличаются **только палитрой и настроением**, не техникой и не устройством UI.
Выбор между ними — это выбор цветокора, а не отход от канона.

### Вариант A — «Эпичное HD-2D, янтарь + индиго»
`deep indigo #121a2e` · `teal #1f4a52` · `moss #3f6b4f` · `molten amber #f0a03c` · `gold #ffd98a` · `bone #e8e2d0`
Ночные руины каменного храма, факельный объёмный свет, рыцарь в детализированной
броне с плащом, тёплый bloom, холодные тени. Атмосфера дорогой современной MMO.

### Вариант B — «Аркан-неон, фиолет + циан»
`near-black violet #0e1020` · `indigo #241a4a` · `cyan #38d6e0` · `magenta #d851c8` · `steel #8fa2c4` · `ice #e6f4ff`
Та же руинная локация, но с магической неоновой подсветкой, голограммами,
светящимися рунами, дождём и частицами. Тот же современный HD-пиксель, тот же HUD.

## 6. Переиспользуемый префикс промпта

Каждый промпт = этот префикс + палитра варианта + описание конкретного экрана +
ссылка на якорный кадр `01-hub.png` как эталон стиля.

```
Modern high-resolution pixel art, HD-2D / neo-pixel-art, NOT retro 8-bit,
NOT chibi, NOT cartoon, NOT toy-like, NOT flat 5-color sprites. Dense fine 1px
pixel clusters, highly detailed 64-128px character sprites with realistic human
proportions, rich 24-hue palette, manual dithering and smooth color ramps,
sophisticated lighting: volumetric light shafts, bloom, rim light, ambient
occlusion, atmospheric fog, glowing particles, parallax depth layers, cinematic
depth-of-field background. Mature premium cinematic game art, crisp pixel grid,
no anti-aliasing, no gradients, no 3D render, no vector illustration.
Contemporary MMORPG idle-game UI: sleek dark semi-transparent glass panels,
hairline 1px pixel borders, thin neon accent lines, micro pixel icons, dense clean
data layout, compact segmented bars, no wooden frames, no rivets, no chunky bevels.
Only tiny technical pixel-font glyphs (numbers, LV, HP, DPS, GOLD, +), no long
words, no gibberish text. Portrait 9:16, full-bleed, no phone bezel, no hands.
Shared persistent HUD on every screen: top row with three resource capsules
(coin, gem, energy) plus LV badge and segmented EXP bar; bottom nav with exactly
5 micro icons (hub, sword, hero, bag, map), one highlighted with accent neon.
```

## 7. Статус генерации

| Вариант | 01 | 02 | 03 | 04 | 05 | 06 |
|---------|----|----|----|----|----|----|
| A · Янтарь / индиго | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ * |
| B · Аркан-неон | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |

\* На 12-м кадре сработал лимит генерации «10 картинок за ход», поэтому
`a/06-shop.png` получен **цветокором** кадра `b/06-shop.png` (выборочный сдвиг
 hue насыщенных неоновых зон + лёгкий индиго-тинт), а не отдельной AI-генерацией.
Композиция и «хром» HUD при этом идентичны — варианты по замыслу и есть один и
тот же экран под разным цветокором. При желании кадр перегенерируется AI по
обычному промпту из раздела 6.

Якорные кадры `a/01-hub.png` и `b/01-hub.png` задают стиль; все остальные экраны
сгенерированы с этим кадром в `images` как эталоном. Для обоих вариантов A и B
использован один и тот же префикс промпта и один и тот же «хром» HUD — меняется
только цветокор и источник света (факел против неона).

## 8. Как смотреть

`prototype/index.html` — кликабельный многостраничный прототип: переключатель
варианта A/B, вкладки экранов, стрелки клавиатуры, миниатюры. Картинки лежат в
`prototype/screens/a/` и `prototype/screens/b/`.
