# Defold-скелет (заморожен)

Первый вариант клиента: официальный мобильный шаблон Defold с адаптивным HUD,
пересчётом по `window.get_safe_area()` и `WINDOW_EVENT_RESIZED`.

Проект **не удалён** — он остаётся как референс и как готовая альтернатива,
если по ходу разработки выяснится, что Godot не тянет web-сборку на слабых телефонах.
Открывается в Defold 1.14: `File → Open Project → game.project`.

Актуальный клиент — `/client` (Godot 4).
